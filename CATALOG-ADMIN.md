# Керування каталогом МЕТОН

Каталогом керує вкладка **«Каталог»** у Google Sheets «Замовлення МЕТОН».

## Зміна ціни або наявності

1. Знайдіть товар за ID або назвою.
2. Змініть `Ціна`, `Валюта` чи `Наявність`.
3. Залиште `Активний = Так`.
4. Для готового товару встановіть `Публікація = Готово`.
5. У GitHub відкрийте **Actions → Оновлення каталогу з Google Sheets → Run workflow**.

## Додавання товару

1. Скопіюйте найближчий рядок тієї самої категорії.
2. Створіть унікальний ID латиницею без пробілів.
3. Заповніть назву, категорію, тип, бренд, опис, ціну, валюту та характеристики.
4. Вставте посилання на фото виробника або файл Google Drive з відкритим доступом.
5. Додайте datasheet виробника.
6. Встановіть `Активний = Так` і `Публікація = Готово`.
7. Запустіть workflow оновлення.

Товар без назви або основного фото не публікується. Якщо datasheet відсутній, рядок залишається зі статусом «Потребує перевірки».
